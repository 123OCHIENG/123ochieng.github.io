# Vantyx FX Frontend

A responsive static frontend prototype for the Vantyx FX homepage.

## Run
Open `index.html` directly in a browser, or serve the folder with any static server.

## Notes
- The supplied Vantyx FX logo is included in `assets/`.
- Market ticker/chart values are demo UI data, not live prices.
- Founder portrait is a placeholder and should be replaced with the official image.
- Testimonials and pricing are draft content.
- Before production, connect authentication, real market data, payments, legal pages, and any copy-trading/broker integrations.
